# Fonts

The font files live in freemapper-core now, in `crates/freemapper-render/assets/fonts` (source, commit and
SHA-256 are in the README there). Arimo, metric-compatible with Arial, is embedded in the PDF for every map text
(ADR 0017). Only the licence text stays here, because the release archives ship it as `FONT-LICENSE.txt`.
