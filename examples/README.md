# Beispielprojekte

[English](README.en.md)

Hier liegen fertige Veranstaltungen, gebaut auf Karten aus den
[Beispielen von freemapper](https://github.com/HenryJobst/freemapper/tree/main/examples): Projektdatei,
Bahndatei, die erzeugten PDFs und ein Vorschaubild. Das erste Beispiel wird ein Sprinttraining mit einer
Fenster- und einer Korridorvariante. Es kommt mit der ersten Version, die Blätter drucken kann.
