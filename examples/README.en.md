This folder will hold finished events built on maps from
[freemapper's examples](https://github.com/HenryJobst/freemapper/tree/main/examples): the project file, the
course file, the generated PDFs and a preview image. The first example will be a sprint training with a window
and a corridor variant. It arrives with the first version that can print sheets.
