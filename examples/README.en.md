# Example projects

[Deutsch](README.md)

This folder holds finished events built on maps from
[freemapper's examples](https://github.com/HenryJobst/freemapper/tree/main/examples). Each example has the
project file, its inputs, the generated PDFs and a preview image. Every kind of event gets one example as soon
as the program can print it:

| Example | Shows | From |
|---|---|---|
| [`luebeck-scales`](luebeck-scales/) | the same sprint map at 1:4000 and 1:5000: exact scale, symbols at their printed size | M1 |
| `luebeck-competition-layouts` | one competition with two layouts, A4 1:4000 for older classes and A4 1:5000 for younger ones, with passe-partout, title, north lines, logos and a scale check bar | M2 |
| `schoolyard` | a schoolyard map at 1:1000 on A4 | M2 |
| `luebeck-competition-courses` | the same competition with courses from Purple Pen, control descriptions and control numbers, plus the same courses as IOF XML 3.0 without descriptions | M3 |
| `luebeck-training-window` | window orienteering with a mask variant | M4 |
| `luebeck-training-corridor` | corridor orienteering with a mask variant | M4 |

Tour sheets for control placers, team orienteering and a forest map follow later.
