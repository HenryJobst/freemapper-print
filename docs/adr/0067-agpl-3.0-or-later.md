# 0067. AGPL-3.0-or-later

Date: 2026-11-15
Status: Accepted, supersedes ADR 0002

## Context
ADR 0002 chose GPL-3.0-or-later. The GPL lets anyone run a modified copy as a network service without publishing
the changes. The author holds all copyright in this repository and in freemapper, freemapper-core and the other
app (one author in every history), so the licence can change for new versions. The third-party crates are
permissive or offer a permissive licence as an option (`option-ext` is MPL-2.0); all combine with the AGPL.
Code and files taken from OpenOrienteering Mapper stay GPL-3, which GPLv3 section 13 allows to combine with an
AGPLv3 work.

## Decision
freemapper-print is licensed AGPL-3.0-or-later, as freemapper (ADR 0152), freemapper-core (ADR 0035) and the other app.
Third-party material keeps its licence.

## Consequences
- Whoever runs a modified freemapper-print as a network service must offer its source to the users (section 13). Local use
  does not change.
- Releases up to the last one under the GPL stay GPL-3.0-or-later for those who received them.
- A fork under another name stays allowed, as it was under the GPL.
- Cost if wrong: a user who needs the GPL without the network clause has no licence for new versions; the author
  could grant one.

Source: the licence audit of 2026-11-15; freemapper ADR 0152.
