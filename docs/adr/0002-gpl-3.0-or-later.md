# 0002. GPL-3.0-or-later

Date: 2026-11-08
Status: Accepted

## Context

freemapper is GPL-3.0-or-later (its ADR 0006) and embeds OOM's GPL symbol sets. freemapper-print reuses
freemapper's renderer and may port parts of OOM's renderer, which is GPL-3.0 too. Purple Pen, whose control
description symbols and `.ppen` format matter here, is BSD-style and can be combined with the GPL.

## Decision

freemapper-print is licensed GPL-3.0-or-later.

## Consequences

- freemapper code and OOM code can be used and ported directly.
- Anyone who distributes freemapper-print or code built on its library must do so under the GPL.
- Cost if wrong: relicensing needs the consent of every contributor and replacements for the GPL code taken
  from freemapper and OOM.

Source: brainstorming 2026-11-08 (renderer research); freemapper ADR 0006.
