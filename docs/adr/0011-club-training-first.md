# 0011. Club training first

Date: 2026-11-08
Status: Accepted

## Context

The user prints on a home printer or in a copy shop as well as in print shops. Club training in town and park
terrain is the first use: sprint maps, A4, window and corridor exercises.

## Decision

The first version targets club training: `.omap` maps, sprint and schoolyard symbol sets, A4 and A3, courses
with masks, and an office print PDF with the course overprint simulated so that the map shows through. The
press PDF (PDF/X, bleed, crop marks, spot colour) and OCAD maps come later.

## Consequences

- The first milestones stay small enough to use for a real training early.
- Cost if wrong: a club that only prints in a print shop cannot use the first version for that.
