# M2 Layouts and Sheet Elements Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An event project file with several layouts turns a finished map into finished print sheets: passe-partout,
title block, logos, texts, scale check bar, credit and copyright line, and north lines where the map has none, with
German and English program texts and the commands `init`, `check` and `export`.

**Architecture:** A TOML project file (`freemapper-print.toml`) describes the event, the map source, shared sheet
elements and 1–5 layouts. `render_sheet(project, layout)` builds on M1's `render_page`: the map is clipped to the
layout's map frame, and a new sheet layer in `RenderedPage` (direct colours and raster images, painted after the map)
carries the sheet elements, so the PDF writer and a later SVG backend draw the same value. Program texts move into
Fluent files with the language detection copied from freemapper-courseplan.

**Tech Stack:** Rust 2024; existing crates (pdf-writer, quick-xml, serde, toml, clap, anyhow, ttf-parser,
subsetter); new: fluent-bundle =0.16.0, unic-langid =0.9.6, fluent-langneg =0.14.2 (versions agreed with
freemapper-courseplan), image (PNG/JPEG decoding; freemapper uses 0.25.10 with features jpeg, png), usvg (SVG to
paths), a crate for free disk space (fs4 or equivalent). Every new crate at least two weeks old.

**Spec:** `docs/superpowers/specs/2026-11-08-freemapper-print-design.md` (§2, §4, §5.4, §5.5, §5.6, §5.9, §5.10, §7).
ADRs 0008 (one project file), 0016 (AI optional), 0018 (scale rule), 0019 (limits), 0020 (page output), 0023
(north lines).

## Global Constraints

- Every dependency version is at least two weeks old; pin exactly with a comment when the latest release is younger
  (ADR 0006). Toolchain 1.99.1. fmt, `clippy --workspace --all-targets -- -D warnings` and tests green after every
  task. `unsafe_code = "forbid"`. Pure Rust.
- Code, comments, specs, plans and ADRs in English; README, manual, examples README and changelog in German and
  English; all user-facing text (program messages, help, docs, ADRs) through the unslop and humanizer rules.
- Glossary first: new terms get a row in `docs/glossary.md` with the code.
- Exact scale stays exact: page size = paper size, 1 mm at print scale = 1 PDF mm, symbol sizes per ADR 0018.
- Scale and contour interval must appear on every sheet (ISOM 2.13); maps larger than A3 get a warning
  (ISSprOM 3.4).
- North lines from the map are always drawn and never replaced; generated ones only when the map has no 601
  objects (ADR 0023, design §5.9). Ground spacing: sprint 120 m, forest 300 m, schoolyard 37.5 m (freemapper's
  value, marked unverified).
- Every PDF names freemapper-print and https://github.com/HenryJobst/freemapper-print (metadata always; visible
  credit line on by default, switchable per event).
- Program texts: Fluent files `crates/freemapper-print-cli/i18n/{en,de}/freemapper-print.ftl`; English is the
  reference and fallback; language from `--lang`, `FREEMAPPER_LANG`, `LC_ALL`, `LC_MESSAGES`, `LANG`; first value
  whose language part matches an available language wins; unknown `--lang` is a usage error.
- Limits for hostile input (ADR 0019) cover sheet elements too: images and SVG logos are bounded in size and work.
- Commit trailer on every commit:
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` and
  `Claude-Session: https://claude.ai/code/session_01BW25Yox679dWdd3YRayCBm`.

## Review Focus

1. A project file with a typo (unknown key, wrong type, missing map file, layout id used twice) must stop with a
   message that names the file, the line and the field, never panic or silently ignore it. Pinned in Task 3.
2. Paths in the project file are relative to the project file, also when the command runs from another folder.
   Pinned in Task 3 and Task 10.
3. A logo file that is huge, corrupt, or an SVG with thousands of nodes must not hang or exhaust memory; it is
   skipped with a note. Pinned in Task 8.
4. A sheet element that does not fit (logo larger than the passe-partout, text longer than the map frame) is drawn
   anyway, clipped to the page, and `check` reports it. Pinned in Task 5 and Task 10.
5. Exporting into a folder on a full disk leaves no half-written PDF and says the disk is full. Pinned in Task 1.
